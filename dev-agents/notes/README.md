# Agent 交接物（notes/）

每包完成后在**这里**写 `<包名>.md`（如 `21-coverage-engine.md`）。下一阶段 Agent 开工前先读依赖包的交接物。

## 交接物模板

```markdown
# <包名> 交接物
- 完成 Agent：<编号>  日期：<日期>
## 1. 实现清单
- 文件 + 关键符号（服务函数/路由/类）
## 2. 未实现 / 待定
- （明确写出，不藏）
## 3. 对下游包的依赖假设
- 你假定别人提供了什么（接口签名/表/端点）
## 4. 自测结果
- 关键测试输出（贴 1-3 行结论）
## 5. 给下游的注意事项
- 接口契约、陷阱、已知 bug
```
